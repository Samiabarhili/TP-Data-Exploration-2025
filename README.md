# Employee Salary Clustering Analysis

This project performs a multivariate statistical analysis of employee data to explore salary patterns and identify employee profiles.

## Objectives

- Explore relationships between salary, experience, age and education
- Identify salary patterns across employee categories
- Detect groups of similar employee profiles using clustering methods

## Methods

The analysis includes several statistical techniques:

- Descriptive statistics
- Principal Component Analysis (PCA)
- Linear regression
- ANOVA
- K-means clustering
- Hierarchical clustering

## Tools

- R
- FactoMineR
- factoextra

## Key variables analyzed

- Starting salary
- Current salary
- Age
- Professional experience
- Seniority
- Education level
- Socio-professional category
